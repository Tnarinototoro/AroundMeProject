# AroundMeProject

**A Life Vibe App** — UE5 驱动的 AR / 移动端生活方式游戏。

## 组件

- `AroundMe/` — 主游戏项目（UE 5.5）
- `PlayGround/` — 独立测试 / 试验项目（UE 5.4）
- `AroundMeLib/` — Android 配套库（`com.aroundmelib`），通过 `DIYPlatformService` 与游戏通信
