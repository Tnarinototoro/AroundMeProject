## 五、文本镜像（只读，给 AI 与检索用）

- **生成物**：仓库根 `_docs_txt/`，目录结构与 `Docs/` 一致，一个源文件对应一个 `.txt`。Office 文件抽取正文（含 docx 批注、pptx 备注页、xlsx 全表）；**`.md` 文档原样镜像**。
- **支持格式**：`.docx` / `.pptx` / `.xlsx` / `.md`。目录内的 `README.md` 是索引本身，不作为被抽取的资料。
- **生成器**：`_tools/docs_sync.py`，**以本 README 为准**：
  - README「一、现行」里用反引号登记的路径 = 会被抽取的清单；
  - 物理存在但没登记的文件 → 仍然抽取，但标「未登记」并告警（反向检查 README 有没有漏）；
  - 登记了但文件不存在 → 告警；
  - `_Deprecated/` → 不抽取，只在索引里列出。
  - 注意：正文里**用反引号括起来的路径**也会被当作登记项，写说明文字时请避免给不存在的文件加反引号。
- **同步命令**：`python _tools/docs_sync.py` → 重写 `_docs_txt/` 与其中 `00_INDEX.md`。
- **注意**：镜像永远滞后于原文，**一切以原文为准**；新增或移动文档后请重跑一次。
